# 돌봄의 울림 · 글자 없는 벡터 심볼

2026-09-20 · Baby Care 로고 디자인 제안. 서비스 화면이나 앱 아이콘에 적용한 상태는 아니다.

작은 원은 아기가 보내는 신호, 짧은 곡선은 소리의 울림, 이를 감싸는 큰 곡선은 보호자의 돌봄을 추상적으로 표현한다. 특정 감정이나 원인을 확정하는 얼굴·문구·의료 기호는 넣지 않았다.

## 파일

| 파일 | 용도 |
|---|---|
| care-signal.svg | 네이비 등 어두운 배경용. 핑크와 브릭 레드, 투명 배경 |

## 색과 형태

- 핑크: `#FF9398`
- 브릭 레드: `#D14836`
- 네이비: `#1D1841`
- 단색: `#000000`, `#FFFFFF`
- 아이보리, 글자, 폰트 의존성, 그라데이션, 외부 파일 참조, 내장 비트맵 없음.
- 컬러/단색 원본의 viewBox는 `48 48 416 416`이다. 두 개의 닫힌 채움 경로와 하나의 원만 사용하며 획 두께에 의존하지 않는다.
- 세 도형은 독립적으로 편집 가능하다. 접근성을 위한 title/desc는 화면에 표시되는 글자가 아니다.

## 사용

- 가로세로 비율을 유지한다. 네이비 배경의 기본 UI에는 `care-signal.svg`를 사용한다.
- 주변 요소와는 로고 전체 폭의 약 1/8 이상 여백을 확보하는 것을 권장한다.
- 기본 UI 적용은 32px 이상을 권장한다. 16px favicon처럼 작은 공간에서는 단색 파일을 우선하고 실제 배경에서 확인한다.
- 로고 자체에 회전·늘이기·그림자·윤곽선을 추가하지 않는다.
- 보조 기술에는 상황에 맞는 이름을 제공한다. 중복 장식 로고라면 소비 화면에서 숨긴다.

## 확인 범위

SVG 구조, 사용 색, 투명 배경, 외부 참조 부재를 검사하고 128·64·32·24·16px에서 네 가지 변형을 렌더해 확인했다. 앱 연결, 실제 기기 화면, 인쇄 교정이나 상표 검토를 수행했다는 의미는 아니다.
