## 3. 현재 모델 학습에 맞춘 판단 시점

9월 19일 19:32 관측에서 군집 보조 학습은 **2,530회 갱신·20,240회 입력**까지 진행했다. 최근 200회 갱신의 처리량으로 계산한 남은 순수 학습 시간은 **약 8.6시간**이다. 이는 3회차 최대 입력량 기준이며 검증·저장·전원/공간 대기를 제외한다. 완료 시각을 보장하는 값은 아니다.

1. 현재 k32 학습을 유지한다. 이번 계획에서 학습을 중단하거나 추가 MPS 학습을 시작하지 않는다.
2. 완료 후 `completion_check.json`·선택 인코더·재로딩 검증과 잠금 해제를 확인한다. 진행 중 폴더의 초기 best 모델을 최종 학습 모델로 잘못 선택하지 않는다.
3. **첫 서비스 연결은 기존 실행기가 지원하는 기본 SSL → Donate 분류 경로를 우선한다.** 이미 완료된 기본 인코더도 원인 분류기 학습은 필요하다.
4. k32 인코더 선택과 출처 검사 확장을 마쳤고 시간이 확보되면 같은 fold/seed로 k32 경로를 실행한다. 검증 지표로 선택하며, 군집 보조 모델이라는 이유만으로 우선 배포하지 않는다.
5. 제출 전 Enes 가중치 탐색·여러 seed·전체 군집 수 비교를 늘리지 않는다. 첫 한 fold는 개발 검증이며 정식 3개 분할 비교와 구분한다. 최종 시험 자료로 튜닝하지 않는다.
6. **08시에도 현재 학습이 진행 중이면** 모델 연결 일정이 밀린 것으로 표시하고 API/기록/음원 경로를 계속 완성한다. 자동 중단·잠금 우회·동시 GPU 학습을 하지 않는다.
7. **13시까지 실제 모델 공개 조건을 통과하지 못하면** REAL 후보 기능을 미준비로 유지한다. 배포 링크에는 검증된 기록 기능과 명확하게 표시된 개발용 분석 시연을 제공할 수 있으나, 실제 분석 통합 완료나 대회 요건 충족으로 간주하지 않는다. 필수 동작 요건은 접수 규정을 확인한 결과에 따라 판정한다.

실제 모델이 정상 실행됐지만 입력 품질·지원 범위·검증된 신뢰 기준에 못 미칠 때만 근거 있는 ABSTAIN을 사용한다. 모델 적재 실패·시간 초과·미학습 상태는 실패 또는 미준비다. 실제 분석 장애를 STUB으로 자동 대체하지 않는다.

## 4. 링크 제출에서 먼저 확인할 것

- **공개 웹 주소:** HTTPS와 안정적인 호스팅 주소. 첫 화면에서 서비스 목적, 구현 범위, 로그인/체험 방법을 이해할 수 있게 한다.
- **심사 접속 경로:** 배포 보호 설정, 로그인 리디렉션, 초대 만료로 심사자가 막히지 않는지 확인한다. 실제 로그인 흐름과 합성 DEMO 흐름을 구분하고, OWNER/CAREGIVER 권한을 익명 공개하지 않는다.
- **실제 API:** 올바른 API 주소·CORS·Auth 설정을 사용하고, 페이지를 새로고침하거나 다른 기기로 열어도 연결된다.
- **실제 실행 표시:** REAL/STUB과 USER/DEMO를 각각 표시한다. 합성 데이터·고정 응답·학습 중인 모델을 실사용 성능으로 발표하지 않는다.
- **삭제·비밀·운영:** 공개 번들/문서에 서버 키·토큰·개인 음원 URL을 넣지 않고, 만료 음원 정리와 기본 호출 상한을 확인한다.
- **증거:** 배포 버전·검증 시각·입력 출처·두 계정 결과·남은 문제를 기록한다. 링크가 열리는 것만으로 전체 P0 완료를 선언하지 않는다.

## 5. 제출본과 전체 P0의 차이

| 상태 | 판정 |
|---|---|
| 웹/API URL만 열림 | 첫 배포 완료 |
| STUB으로 두 계정 핵심 흐름 통과 | 개발 연결 확인 |
| 실제 분석 또는 근거 있는 유보 + 확인 기록 + 다른 보호자 반영 | 첫 실제 통합 시연 완료 |
| 감지·정규화·안내·요약·알림·학습 후보를 포함한 AC01~AC44 전체 실검증 | 전체 P0 완료 |

**제출 우선순위는 배포와 핵심 흐름의 순서 조정이다. 기존 P0 범위의 삭제나 계약 변경이 아니다.** B-08·B-10·B-11·B-12, B-07의 미완료 범위 및 전체 인수는 상세 계획의 완료 조건을 그대로 따른다.

이번 작업은 진행 현황 조사와 계획 수립까지다. 새로운 서비스 URL은 생성하지 않았고, 실제 API·Supabase·Cloud Run·기기 검증을 수행하지 않았다.
