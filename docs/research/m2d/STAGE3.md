# 3단계: BABYCRY 입력 준비

> 연구 문서 보관본입니다. 본문의 실행 명령·파일 경로는 별도 학습 프로젝트를 기준으로 합니다. 단계별 범위, 과거 기록과 외부 의존성은 [연구 문서 안내](README.md)를 먼저 확인합니다.

프로젝트의 `.venv`를 활성화한 터미널에서 실행합니다.

```sh
caffeinate -i python prepare_stage3.py
```

## 수행 내용

1. 메타데이터와 실제 WAV 목록을 대조합니다. 메타데이터의 `.wav`와 실제 `.WAV` 표기를 맞춰 비교합니다. 음성 파일이 없는 메타데이터 행 25개는 제외합니다. 길이 정보가 비어 있는 경우 WAV 헤더에서 읽습니다.
2. 모든 WAV를 실제로 읽습니다. 원본은 그대로 두고, 메모리에서 모노·16kHz로 변환한 뒤 M2D의 80 Mel 스펙트로그램을 저장합니다. 별도의 16kHz WAV 사본은 만들지 않습니다.
3. 아기 ID가 같거나, 녹음기 ID와 원본 녹음 파일명이 같거나, 해독한 음성이 정확히 같은 데이터는 같은 그룹으로 묶습니다. 그룹을 유지하면서 아기 수 기준 약 80:10:10으로 학습·검증·시험을 나눕니다. 동일 음성은 대표 파일 하나만 목록에 남깁니다.

## 저장되는 파일

- `data/babycry_m2d/spectrograms/`: float32, `[1, 80, 시간 프레임]` 배열
- `data/babycry_m2d/manifests/train.csv`, `val.csv`, `test.csv`: 분리된 데이터 목록
- `data/babycry_m2d/manifests/train_1000.csv`, `train_10000.csv`: 학습 분할 안에서 여러 아기를 고르게 고른 예비 실험 목록
- `data/babycry_m2d/manifests/excluded.csv`: 무음·오류·동일 음성 제외 내역
- `data/babycry_m2d/preprocessing.json`: 설정, 패키지 버전, 원본 목록 해시
- `data/babycry_m2d/progress.sqlite3`: 이어서 처리하기 위한 진행 기록
- `data/babycry_m2d/train_statistics.json`: 학습 분할에서만 계산한 입력 통계
- `reports/stage3_check.json`: 전체 전처리 완료 및 오류 여부

추가 스펙트로그램 용량은 약 16GB로 예상합니다. 실제 요구 공간은 실행할 때 계산하며, 여유 공간을 남겨 둡니다. 모델 학습은 시작하지 않습니다.

## 중단과 재실행

`Ctrl+C`로 중단하고 같은 명령을 다시 실행할 수 있습니다. 설정과 원본 목록이 동일한지 먼저 확인합니다. 이미 변환한 파일은 해시·형태·수치가 유효한지 확인하고 재사용합니다. 손상되거나 저장이 끝나지 않은 결과는 다시 만듭니다. 동시에 같은 출력 폴더를 처리하지 못하도록 잠금이 있습니다.

원본이나 설정이 달라졌다면 기존 결과를 섞지 않고 중단합니다. 이때 원인을 확인하거나 `--output`으로 새 출력 폴더를 지정합니다.

## 완료 기준과 다음 단계

전체 처리가 끝나고 오류가 없으면 `ready_for_training: true`가 기록됩니다. 이는 **데이터 준비 완료**를 뜻하며, 모델 성능이나 본학습 완료를 뜻하지 않습니다. 손상된 음성은 보고서와 제외 목록에 기록하고 `ready_for_training`을 false로 둡니다. 소리가 정확히 0인 파일과 정확히 같은 음성은 제외 이유를 기록하고 학습 목록에서 뺍니다. 유사 음성 탐지는 별도로 수행하지 않습니다.

아직 학습을 위한 길이 맞추기, 마스킹, 입력 정규화는 적용하지 않습니다. 긴 파일을 미리 잘라 버리거나 짧은 파일을 고정 길이로 채우지 않고 전체 길이와 유효 프레임 수를 보관합니다. 4단계에서 짧은 음성 처리 정책, 정규화, MPS 학습 루프, 학습률·EMA 일정, 검증, 체크포인트 저장·재시작을 구체화합니다. 공식 학습 루프의 CUDA 의존성을 그대로 실행하면 안 됩니다.

학습 통계는 패딩 전 전체 학습 스펙트로그램의 픽셀 기준 진단값입니다. 공식 구형 M2D의 기준값 `[-7.1, 4.2]`와 함께 기록하며, 어떤 정규화를 쓸지는 4단계에서 정합니다. 검증·시험 데이터로 정규화 통계를 맞추지 않습니다.

BABYCRY는 울음 원인 라벨이 없는 추가 자기지도학습 자료입니다. 메타데이터의 의료·출생 정보나 음향 특징을 원인 정답으로 사용하지 않습니다.

## 현재 검증 범위

- 전체 메타데이터/WAV 이름 대조: 107,312개, 아기 1,000명.
- 실제 음성 32개로 변환 확인: 2.4~94.08초.
- 그중 5개를 공식 `ToLogMelSpec` 결과와 비교: 최대 절대 오차 0.
- 아기·녹음·동일 음성 분할 격리, 고정된 분할 결과, 예비 학습 목록 선택 검사.
- 무음·NaN 처리와 변환 결과 손상 탐지 검사.
- 전체 107,312개 디코딩/전처리는 사용자가 위 명령을 실행해야 완료됩니다.
