- **기기·브라우저:** Windows 로컬 호스트, Chrome 153.0.8010.48(오디오 화면 일부), Codex 인앱 브라우저(Chromium 엔진의 정확한 버전은 제공되지 않음, 실제 OTP·API 화면). Node 22.18.0, npm 10.9.3, Python 3.12.14(격리 venv), Docker Engine 29.8.0, Next 16.3.5, FastAPI 0.141.1.

- **시험 역할:** 서로 다른 `example.test` Mailpit 수신함 3개를 OWNER, CAREGIVER, 비구성원으로 사용했다. 아기 별칭·생년월일·기록은 합성값이다. 운영 자격 증명이나 실제 아기 자료는 사용하지 않았다. OTP·JWT·초대 링크는 이 문서, Git, 저장 로그에 남기지 않았다. 수신함과 일회용 값은 격리 스택의 임시 상태다.
- **정책:** `NEXT_PUBLIC_POLICY_PROFILE=LOCAL_SYNTHETIC_V1`의 합성 문구만으로 SHARED_USE 수락을 확인했다. 운영 문구·권리 확인·실제 아동 자료 처리 승인이 아니다. Realtime은 SEC30·SEC31 채널 회수 증거가 없어 비활성.
- **증거 위치:** 아래 E01~E08의 민감정보 제거 관측 기록이 이 문서에 있다. 기존 합성 검사·로컬 API 증거는 [선행 로컬 기록](./a03-a04-a08-local-2026-09-20.md), [A-02 기기 표](../a02-audio-device-check.md)를 참고한다. 원시 Mailpit 메시지, 브라우저 세션, 토큰 URL은 첨부하지 않았다.

## 수정 회귀와 병합 점검

격리 브랜치를 시험 도중 전진한 `origin/develop=1b861126` 위에 재배치한 뒤 API Ruff 검사와 Linux 대상 mypy(53 source files), 웹 typecheck·lint·Vitest **25파일 117개**, Next 프로덕션 빌드, API Docker 이미지 빌드를 통과했다. Linux 컨테이너의 FastAPI TestClient에서 허용 출처 preflight 200, 거부 출처 400, 미설정 API의 fail-closed 503 응답에도 허용 출처 CORS 헤더가 붙는 것을 확인했다. 처음 작성한 회귀 시험은 미설정 API를 401로 잘못 예상했으며 실제 503에 맞춰 바로잡았다. 이 결과는 전체 API pytest 통과 주장이 아니다. 최종 웹 정적 번들에서 알려진 서비스 역할·DB·OpenAI 비밀값 이름 패턴은 0건이었다.

2026-09-20 KST 점검 당시 열린 PR은 #28(B-11 API)과 #32(캐릭터 합성 모션)였다. 최종 브랜치 HEAD와 각 원격 PR 브랜치를 `git merge-tree --write-tree`로 비교한 결과 둘 다 충돌 없이 병합 트리를 만들었다. 이 검사는 PR 리뷰·CI 결과나 이후 원격 변경을 대신하지 않는다.
