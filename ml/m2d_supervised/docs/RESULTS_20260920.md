# M2D 지도학습 실행 결과 · 2026-09-20

## 결론

27회 개발 학습, 고정 비교·선택, 선택 B와 기준 A의 최종 재학습, Donate 봉인 테스트
각 1회 평가, 로컬 전체 모델 내보내기와 새 프로세스 재현을 완료했다.

- 후속 완료 기록·최종 모델·봉인 테스트·export의 전체 해시 연결과 실행 코드 복사본을

개발 중 발생했던 iCloud 특징 파일 읽기 오류는 원본 바이트·체크포인트를 보존하고 복원한

바꾸는 재시도는 하지 않았다. 외부 출력의 diagnostics 및 원래 training.log가 사고 기록이다.

## 개발 비교 및 선택

각 seed에서 3개 fold OOF 예측을 합친 367개 점수의 평균과 seed 표본 표준편차다.

| 레시피 | 평균 Macro-F1 | seed 표준편차 | 결과 |
|---|---:|---:|---|
| A · 원본 M2D + Donate | 0.211058 | 0.003050 | 비교 기준 |
| B · BABYCRY SSL + Donate | 0.218613 | 0.010809 | 선택 |
| C · BABYCRY SSL + Donate/Enes 분리 head | 0.215787 | 0.014296 | 조건 미충족 |
| train-fold 다수 클래스만 예측 | 0.181872 | 해당 없음 | 단순 기준 |

C는 단독 우승자 B 대비 평균 -0.002826이며 3 seed 중 1개만 개선했다.
비-hungry 라벨 평균 recall 감소 조건은 통과했지만 +0.02 및 2/3 seed 개선 조건은 실패했다.
Enes를 사용한 9회 공동학습은 완료했지만 최종 B에는 Enes head가 없다.

고정 2,000회 짝지은 녹음 그룹 bootstrap(174개 그룹)의 B-A 차이 95% 구간은
[-0.000804, 0.019945], C-B는 [-0.015259, 0.010520]이다. 모두 0을 포함한다.
이는 고정 seed들에 조건부인 표본 불확실성이며 seed 표준편차와 구분한다.
Donate의 녹음/출처 그룹은 검증된 실제 아기 식별자가 아니고, 희소 라벨 그룹도 적다.

선택 epoch는 B [2,2,8,7,1,3,4,1,4]의 중앙값 3, A [2,2,8,7,1,3,2,1,4]의
중앙값 2로 테스트 전에 고정했다. 테스트 결과로 선택·횟수를 바꾸지 않았다.

Enes 개발 OOF clip Macro-F1은 seed 42/43/44 각각 0.367720/0.329225/0.342969이다.
baby 동일가중 평균은 0.288524/0.248660/0.266756,
bout 동일가중 평균은 0.149950/0.143461/0.150821이다. 그룹별 원래 값은 comparison.json에
보존했다. Enes 라벨은 울음을 멈추게 한 보호자 행동의 보고이며 의학적 원인 정답이 아니다.

## 봉인 테스트 결과

Donate 테스트 90개, 녹음 그룹 47개에 대해 모델마다 정확히 한 번 추론했다.
C가 선택되지 않았으므로 Enes 테스트 5명/7,623개에는 모델 추론을 수행하지 않았다.

| 모델 | Macro-F1 | 라벨 일치율(accuracy) |
|---|---:|---:|
| 선택 B | 0.232821 | 0.800000 |
| 기준 A | 0.181818 | 0.833333 |
| 항상 hungry | 0.183133 | 0.844444 |

hungry가 90개 중 76개라 accuracy만으로 품질을 평가하면 안 된다. B의 라벨별 결과:

| 라벨 | 개수 | precision | recall | F1 |
|---|---:|---:|---:|---:|
| belly_pain | 2 | 0 | 0 | 0 |
| burping | 2 | 0 | 0 | 0 |
| discomfort | 5 | 0.200000 | 0.400000 | 0.266667 |
| hungry | 76 | 0.875000 | 0.921053 | 0.897436 |
| tired | 5 | 0 | 0 | 0 |

B는 hungry 80개, discomfort 10개만 예측했다. A도 belly_pain·burping·tired 예측이 없다.
원래 라벨 순서의 혼동행렬, 모든 예측과 A의 라벨별 지표는 평가 산출물에 보존했다.

테스트 B-A Macro-F1 차이는 +0.051002이나 2,000회 짝지은 그룹 bootstrap 95% 구간은
[-0.009168, 0.123271]이다. B 자체의 구간은 [0.173584, 0.306101]이다.
희소 라벨 표본이 매우 적으므로 유의한 성능 향상이나 실제 원인 정확도를 주장하지 않는다.

## 남은 서비스 작업

   검증한다. 이 봉인 테스트를 새 임계값/레시피 튜닝 자료로 재사용하지 않는다.
3. **A-02/B-05/B-06:** 실제 지원 기기·브라우저 녹음, 고정 디코더, 음질·비울음·OOD,
   짧은 입력과 처리 지연·동시성·메모리를 검증한다. 현재 3gp 재현은 macOS 디코더 기준이다.
4. **B-06/A-06:** REAL/STUB과 USER/DEMO를 분리하고 COMPLETE/ABSTAIN/FAILED,
   응답 유실·동일 분석 복구·권한 회수·삭제 중 늦은 결과를 실제 API/두 계정으로 시험한다.
5. 서비스 배포와 운영 검증은 별도 작업이다. 현재 모델을 검증된 5원인 판별기로 소개하거나
   score를 실제 원인 확률로 표시하지 않는다. 데이터·라벨·불균형 개선은 새로운 설계와
   독립 평가 계획을 확정한 뒤 진행할 후속 연구다.
