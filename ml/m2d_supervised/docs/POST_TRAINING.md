# M2D 개발 학습 이후 실행

담당: B의 내부 모델 검수·내보내기. 기존 서비스 API·계약·배포는 변경하지 않는다.
사용자의 2026-09-20 후속 실행 지시에 따라 27회 개발 완료 후 비교부터 로컬 내보내기까지
진행한다. 아래 기능의 구현과 실제 실행 완료는 별개이며, 완료 기록을 확인한다.

## 실행과 단계 기록

기존 실행과 같은 연구 루트·출력 루트·M2D 소스 루트·고정 설정을 사용한다.
패키지 루트에서 기존 가상환경 Python으로 다음 명령을 호출한다.
공통 경로 인자는 기존 README의 실행 예제를 따르며 원본 연구 디렉터리는 바꾸지 않는다.

```text
python -m m2d_supervised compare <공통 경로 인자>
python -m m2d_supervised launch-post <공통 경로 인자>
```

- `compare`: 원래 개발 실행 코드 복사본과 설정, 정확한 27개 완료·산출물 해시, 검증
  예측·그룹·epoch·노출량을 점검하고 비교 및 선택 계획을 고정한다. 테스트 입력은 읽지 않는다.
- `launch-post`: 검증한 패키지의 해시별 코드 복사본에서 caffeinate 보호 프로세스를 실행한다.
  연구·SSL·MPS 공용 잠금, AC 전원과 8 GiB 이상의 여유 공간 보호를 유지한다.
- `post_training/state.json`, `training.log`, `launch.json`이 후속 상태를 나타낸다.
  개발 단계의 `matrix_progress.json`과 원래 코드 복사본은 변경하지 않는다.
- 실패·중단은 완료가 아니다. 원인을 확인한 뒤 **원래 후속 코드 복사본**에서 `--resume`을
  명시한다. 자동으로 코드·설정·학습 횟수를 바꾸거나 재시도를 반복하지 않는다.

## 비교·선택 규칙

각 seed의 세 fold 검증 예측을 합쳐 고정 5라벨 Macro-F1을 계산한다. 세 seed 평균과
표본 표준편차, fold별·라벨별 수치, 예측 소실 클래스, train-fold 다수 클래스 기준,
실제 실행 epoch·노출량·시간을 함께 보존한다. Enes는 clip 및 baby/bout별 점수를 따로 낸다.

2,000회 bootstrap은 녹음 그룹을 복원 추출하고 모든 레시피·seed에 같은 추출을 적용한다.
각 반복에서는 고정된 세 seed 점수의 평균을 사용한다. 이는 학습 seed를 다시 추출한 구간이
아니며, Donate 그룹을 실제 아기 식별자로 간주하지 않는다. 희소 라벨과 그룹이 적어
구간은 불안정할 수 있다. 없는 라벨은 Macro-F1에서 제외하지 않고 0점으로 처리한다.

단독 A/B 평균의 우위로 선택하며 정확한 동률이면 B다. C는 **이 단독 우승자** 대비 평균
+0.02 이상, 3 seed 중 2개 이상 개선, 모든 non-hungry 라벨의 평균 recall 감소 ≤0.05를
동시에 만족해야 채택한다. 기준 모델은 A→B, B→A, C→B다.

`comparison.json`과 `selection_plan.json`은 다르면 덮어쓰지 않는다. 선택 계획에는
각 레시피의 아홉 선택 epoch 중앙값과 seed 42, 테스트 평가 대상이 포함된다.

## 최종 학습·봉인 테스트

새 초기 가중치에서 Donate 개발 전체를 사용한다. C만 Enes 개발 19명을 함께 쓰며,
분리 head·0.25 손실·baby→bout→cry 표본 추출·동일 노출량을 유지한다. 기존과 같은
warmup/finetune 경계를 쓰되 계획의 총 epoch에서 종료한다. 중앙값이 3 이하이면
head-only 학습만 수행하며 finetune을 억지로 추가하지 않는다. 조기 종료·재선택은 없다.

시작 전에 실제 개발 음원→log-mel→모델 입력이 준비된 특징과 같은지 점검한다. 작은
별도 MPS 예비 실행에서 연속 2 update와 1+재개 1 update의 가중치 해시 일치를 확인한다.
이 예비 실행은 최종 모델·27회 개발 결과와 별도 경로에 남긴다.

두 최종 모델의 완료·해시가 고정된 `evaluation_plan.json` 이후에만 테스트를 평가한다.
Donate 테스트는 모델별 1회다. C를 선택하지 않으면 Enes 테스트는 추론하지 않는다.
평가 직전 claim을 저장하고 결과·완료 해시를 연결한다. 완료된 평가는 다시 추론하지 않는다.
claim만 있고 결과가 없으면 `AMBIGUOUS_SEALED_TEST`로 닫히며 임의 재평가하지 않는다.
결과는 있지만 완료 기록 저장만 끊긴 경우에는 그 결과를 사용해 완료 기록만 복구한다.

## 내보내기와 사용 경계

`post_training/export/selected/`에는 전체 인코더+학습 head 가중치, 설정, 라벨, 버전,
평가·전처리 재현 결과와 해시를 저장한다. 기존 초기 가중치나 부분 체크포인트 없이
새 프로세스에서 다시 읽고 Donate 개발 입력 5개의 출력 일치를 확인한다.

`inference.load_bundle`은 설치된 고정 M2D **구조 코드**와 이 Python 패키지가 필요하지만,
원래 가중치·학습 데이터는 필요하지 않다. 전체 가중치는 로컬 비공개 전용이며 저장소나
PR에 넣지 않는다. M2D 원본 소스·원본 음원을 재배포하지 않는다. 음원 전처리를 쓰려면
`inference` 선택 의존성이 필요하며 일부 원본 3gp는 macOS `afconvert`를 사용한다.
다른 운영체제의 디코더 지원은 별도 검증 사항이다.

제품 후보는 Donate head다. 출력 score는 보정된 실제 원인 확률이 아니다.
`calibration_status=NOT_VALIDATED`, `release_ready=false`를 유지한다.
실제 FastAPI 연동, 두 계정 권한, 실기기·마이크·음질·비울음·OOD·판단 유보,
정상/실패/유보 상태, 처리시간·메모리 검증과 서비스 배포는 이 작업의 통과 범위가 아니다.

보고한다. 봉인 테스트의 결과를 보고 모델·횟수·데이터 분할을 변경하지 않는다.
