## 비교 대상과 지표 정의

[사전 고정 계획](BALANCED_V2.md)과 [시작·진단 기록](BALANCED_V2_START.md)을 따른다.
모두 새 B 자기지도 인코더와 새 분류기에서 시작했다. 개발 전체로 학습했던 v1 최종 B
분류기를 초기화에 사용하지 않았다.

| 방법 | 실제 학습 방식 |
|---|---|
| natural_head | 자연 분포 각 음원 1회/epoch, 역제곱근 빈도 가중 손실, 인코더 고정 |
| balanced_head | 라벨 균형·출처/음원 순환, **일반 교차엔트로피**, 인코더 고정 |
| balanced_finetune | 같은 균형 추출·일반 손실, 3 epoch 뒤 블록 10·11 및 최종 norm 조정 |

두 균형 방법의 실제 클래스 가중치는 모두 1이다. 상속된 v1의 `training.class_weight`
설명 필드는 v2 실제 손실을 뜻하지 않으며 `balanced_v2.variant`가 우선한다.

한 seed의 세 fold 검증 예측을 합친 367개 OOF에서 고정 다섯 라벨의 F1을 평균한다.
아래 대표값은 이 seed별 Macro-F1 세 개의 평균과 **표본 표준편차**다. fold별 점수의
단순 평균이나 세 seed를 독립 음원 1,101개로 취급한 점수가 아니다.

1. 소수 라벨 자료의 출처별 음질·라벨 일관성과 서로 다른 아기/녹음 수를 검토할 필요가 있다.
   훈련 적합도와 검증의 큰 차이는 그 필요성을 뒷받침하지만 원인을 특정하지는 않는다.
2. 새 실험을 한다면 자료 검토 결과와 독립 평가 자료 확보 방안을 먼저 정하고, 비교 계획을
   사전에 고정해야 한다. 이미 확인한 테스트 90개를 반복 최적화용으로 쓰지 않는다.
3. 기존 v1 B 성능은 학습 예산이 다른 역사적 참고일 뿐 이 통제군과 동일하지 않다.
   이번 결과로 v1 모델의 채택 여부를 자동 변경하거나 서비스 모델을 선정하지 않는다.

요청된 개발 비교와 결과 인계를 마친 뒤 시간별 자동화 `m2d`를 일시중지한다.
