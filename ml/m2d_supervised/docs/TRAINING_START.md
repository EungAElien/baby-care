## 이번에 실행한 학습

| 실험 | 초기 인코더 | 지도학습 |
| --- | --- | --- |
| A | 원본 M2D | Donate 5분류 |
| B | BABYCRY 전체 SSL 최선 인코더 | Donate 5분류 |
| C | B와 같은 인코더 | Donate 5분류 + Enes 3분류 별도 보조 헤드 |

각 실험을 seed 42·43·44와 고정된 3개 fold로 반복해 총 27회 순차 실행한다.
각 seed·fold 안에서는 B → C → A 순서다. 처음 3 epoch는 분류 head만 학습하고,
이후 마지막 두 인코더 블록·최종 norm·head를 최대 20 epoch 미세조정한다.
Donate 검증 Macro-F1이 5 epoch 동안 개선되지 않으면 해당 실행을 조기 종료한다.

Donate 개발 자료는 367개다. C에서는 Enes 개발 19명의 31,578개 후보에서
아기 → 녹음 구간 → 울음 순서로 균형 표본추출한다. 한 epoch의 Enes 사용 개수는
해당 Donate 학습 fold와 같고, 보조 손실 가중치는 0.25다. Enes 전체 자료를 매 epoch
모두 학습시키는 방식은 아니다. 두 데이터셋의 원인 라벨은 합치지 않는다.

Donate 테스트 90개와 Enes 테스트 5명은 학습·검증·모델 선택에서 제외한다.
27회 개발 학습이 끝나면 자동으로 종료한다. 최종 비교·재학습·테스트·내보내기는
이번 실행에 포함하지 않았다.

## 완료 후 태스크

1. 27회 완료 증거·파일 무결성·실제 학습량을 확인한다.
2. 검증 예측을 합쳐 A/B/C의 Macro-F1, 라벨별 recall, 그룹 bootstrap을 비교하고
   이미 고정한 규칙으로 레시피를 선택한다.
3. 선택 레시피와 기준 레시피를 seed 42로 개발 자료 전체에서 각각 새로 학습한다.
4. 선택이 확정된 뒤 봉인된 테스트로 최종 평가하고 독립 모델을 내보낸다.
   새 프로세스에서 다시 읽어 출력 재현을 검증한다.
5. 서비스 연동은 별도 태스크로 진행한다. 비울음·녹음 품질·지원 기기·판단 유보 등을
   확인하기 전에는 `calibration_status=NOT_VALIDATED`, `release_ready=false`를 유지한다.
