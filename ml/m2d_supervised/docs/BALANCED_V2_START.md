## 해석과 후속 확인

초기 실행 속도에 따른 전체 예상은 약 50~70분이다. 실제 종료 epoch와 저장·입출력 지연에
따라 달라지므로 이후 완료 속도로 갱신한다. AC 연결·배터리 100%, 여유 공간 약 12 GiB에서
시작했으며 전원·저장공간 보호와 전역 학습 잠금을 적용했다.

27회와 `comparison.json` 생성, 전체 산출물 해시, 프로세스 종료를 확인한 뒤 비교 결과를
별도 기록한다. 각 방법의 Macro-F1뿐 아니라 소수 라벨 precision/recall, 예측 소실 라벨,
훈련 적합도와 검증 차이, 실제 노출량을 확인한다. 테스트 재평가나 최종 전체 재학습은 하지 않는다.

v2의 실제 손실 선택은 `balanced_v2.variant`가 우선한다. 자연 분포 대조군에는 역제곱근
빈도 가중치를, 두 균형 방법에는 **모든 클래스 가중치 1**을 사용한다. 상속된 v1의
`training.class_weight` 설명 필드만 보고 균형 방법도 가중 손실이라고 해석하지 않는다.
이 동작과 일반 손실 사용은 `test_balanced_v2.py`에서 검증한다.
